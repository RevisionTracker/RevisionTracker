Your data stays on this device

Revision entries are stored in this browser on your iPhone. They are not automatically synchronised to your PC or another phone. Export regular backups.

Install on your iPhone

  1. Host this app on a secure HTTPS website.
  2. Open that address in Safari on your iPhone.
  3. Tap Share → Add to Home Screen, then turn on Open as Web App if shown.
  4. Open the new home-screen icon once while online, then try it offline.

The app files can be hosted free, but a website address is needed for installation and offline caching. See README.md in the download for setup steps.

Revision reminders

Each session can have a reminder offset. Export the week's sessions to Apple Calendar and add the calendar file on your iPhone. Calendar sends the alert even when this app is closed. Re-export after changing your timetable.

Push notifications (advanced setup)

Once your account backend is configured, you can enable push alerts for this Home Screen app. On iPhone, add this site to your Home Screen first. Push alerts need a small server-side scheduler; they cannot be reliably scheduled by a static webpage alone.

Owner setup checklist

The source download includes the database SQL and push scheduler code. You must configure them before accounts or push notifications can work. Never put a Supabase service-role key or push private key in the public GitHub repository.

  1. Create a Supabase project.
  2. Run supabase/setup.sql in its SQL Editor.
  3. Copy the Project URL and publishable/anon key into supabase-config.js.
  4. Deploy the included Edge Function and configure the private secrets to enable timed push reminders.
  5. Upload the updated website files to GitHub Pages.
