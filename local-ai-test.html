Checking browser support…

1. Choose a test model

Start with the tiny model to test compatibility. It is not powerful enough to be our finished study planner; this first test is only to prove local inference works.

The first download is several hundred megabytes. Use Wi-Fi, keep the page open, and make sure your phone has free storage and battery. A larger model may cause Safari to close the page on some iPhones.

Model not loaded. Nothing will download until you press the button.

2. Run a simple test

Once the model has loaded, ask it a short question. The answer is generated on your device rather than sent to a paid AI inference API.

Your response will appear here.

3. What to report back

  • Did the support check say WebGPU is available?
  • Did the model finish downloading and loading, or did Safari close the page?
  • Did the test produce a response, and was it coherent?
  • Roughly how long did the first download and response take?
Limits to know: the model weights and browser library are downloaded from the internet. Model inference happens locally, but this test does not guarantee future offline use. This tiny model may give weak or incorrect educational advice, so do not rely on its plan for real exam preparation.
Prototype only. WebLLM requires a compatible browser with WebGPU. See the official WebLLM documentation. The local model is not trained by us; Revision Intelligence is the specialised system we will build around it.
